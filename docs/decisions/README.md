# Registro de decisiones

Crear `NNNN-titulo.md` desde [TEMPLATE.md](TEMPLATE.md) para decisiones con consecuencias duraderas. Estados: propuesta, aceptada, sustituida. Una decisión propuesta no obliga al equipo. Al sustituir una decisión, enlazar la nueva y conservar el historial.

Primera decisión pendiente: producto, tecnologías y límites entre funcionalidades.
